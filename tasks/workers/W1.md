# W1 · Dados e ferramentas

**Objetivo:** dar ao agente os "sistemas" da empresa: carregar os CSVs num SQLite e expor as ferramentas de `docs/ferramentas.csv` com efeito real e log.

**Pode editar:** `src/atendimento/dados/**`, `src/atendimento/ferramentas/**`, `tests/test_dados_*.py`, `tests/test_ferramentas_*.py`, `tests/fixtures/dados/**`.

**Entregas (em ordem):**
1. `atendimento.dados.carga`: `python -m atendimento.dados.carga [--origem docs] [--destino var/atendimento.db]` cria o SQLite com uma tabela por CSV (EC-21: UTF-8, separador confirmado, contagem de linhas igual ao CSV; teste de integração com `@pytest.mark.integracao`). Crie também tabelas novas e vazias para o estado do agente: `acoes_agente` (mesmas colunas de `RegistroAcao`), `aprovacoes` (aprovacao_id, acao serializada, solicitado_por, estado, decidido_por, comentario), `suspeitas`, `mensagens_enviadas`, `classificacoes`.
2. `atendimento.dados.repositorio.Base(caminho_db)`: leitura por ID devolvendo os dataclasses de `contratos.py`: `pedido(order_id) -> Pedido | None` (com itens), `anexos_da_conversa(conversation_id) -> list[Anexo]`, `anexos_por_hash(hash) -> list[Anexo]`, `acoes_com_dinheiro(order_id) -> list[AcaoAnterior]` (histórico `acoes_executadas_sistemas` + `acoes_agente`), `reenvios_do_cliente(customer_id) -> int` (via `trocas_reenvios`), `fila() -> list[dict]`, `mensagens(conversation_id) -> list[dict]`, `cliente(customer_id) -> dict`, `equipe() -> list[dict]`, `politicas() -> dict[str, str]` (chave `secao.regra`). Datas em `datetime` com fuso `contratos.FUSO`.
3. `atendimento.ferramentas.Ferramentas(base)`: método `executar(acao: AcaoProposta) -> RegistroAcao` para: `responder_cliente`, `classificar_conversa`, `solicitar_foto`, `informar_status`, `abrir_chamado_transportadora`, `reenviar_produto`, `reimprimir_personalizacao`, `trocar_produto`, `reembolsar`, `orientar_suspensao_uso`, `negar_por_politica`, `encerrar_conversa`, `solicitar_aprovacao`, `sinalizar_suspeita`, `acionar_pessoa`, `registrar_cosmetovigilancia`, `aprovar_acao`, `rejeitar_acao`. Cada execução grava em `acoes_agente` com `referencia_sistema` (ex.: `REENV-000001`) e `data_hora` = `AGORA`. O campo `sistema` segue os nomes de `acoes_executadas_sistemas.sistema`.
   - **HG-02:** recusar (exceção `FerramentaNaoPermitida`) se o `papel` não está em `papeis_permitidos` de `ferramentas.csv`.
   - **HG-12:** ação com dinheiro idempotente: mesma (ferramenta, order_id, conversation_id, valor) já executada devolve o registro existente sem duplicar.
   - **Não** decide alçada: isso é do W2. A ferramenta só executa o que recebe.
4. Ferramentas de leitura (Q17): `consultar_rastreio(order_id)`, `verificar_pagamento(order_id)` lendo `rastreio_portais_transportadoras` e `pagamentos_gateway`.

**Cenários:** EC-21, HG-02, HG-12, HP-08 (cada ação tem executor, valor, aprovador e referência), HP-09.
